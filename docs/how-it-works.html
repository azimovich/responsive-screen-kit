1Tuzilish

App faqat bitta obyekt bilan gaplashadi: ResponsiveScreens<T>. U facade — o'z logikasi yo'q, har bir chaqiruvni tegishli klassga uzatadi. Ichkaridagi bloklar ochiq, xohlasangiz to'g'ridan-to'g'ri ishlatasiz.

2Sozlash — 3 qadam

① Ekran turlari va qoidalar

enum AppScreen { phone, foldable, tabletMini, tabletBig }

// BIR MARTA, top-level final — build() ichida emas
final screens = ResponsiveScreens<AppScreen>(const [
  Breakpoint(AppScreen.phone),  // base
  Breakpoint(AppScreen.foldable, minWidth: 600),
  Breakpoint(AppScreen.tabletMini,
      minWidth: 600, minShortestSide: 700),
  Breakpoint(AppScreen.tabletBig,
      minWidth: 600, minShortestSide: 1000),
]);

② App'ni bir marta o'rash

void main() => runApp(
  screens.scope(child: const App()), // MaterialApp'dan yuqorida
);

③ Sahifada dizayn chizish

// Butun body farq qiladi
screens.layout(
  builders: {
    AppScreen.phone:      (_) => const OneColumn(),
    AppScreen.tabletMini: (_) => const TwoColumns(),
  },
  landscape: {
    AppScreen.tabletBig:  (_) => const ThreeColumns(),
  },
)

// Faqat bitta qiymat farq qiladi
final gap = screens.value(context, {
  AppScreen.phone: 16.0,
  AppScreen.tabletMini: 24.0,
});

4Flow: fallback — kam builder, kam qiymat

Har tur uchun yozish shart emas. Qiymat topilmasa, oldingi e'lon qilingan turga tushiladi, oxiri base. Qurilma yon tomonda bo'lsa, har qadamda avval landscape, keyin oddiy qiymat tekshiriladi. Shuning uchun base uchun qiymat majburiy.
